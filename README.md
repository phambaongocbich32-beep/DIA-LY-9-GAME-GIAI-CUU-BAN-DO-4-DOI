# Giải cứu bản đồ – Chinh phục vùng Trung du và miền núi phía Bắc

Trò chơi giáo dục tương tác môn Địa lí, gồm 5 chặng thử thách, chế độ chơi cá nhân và thi đấu 4 đội.

## Cách chạy

Mở file `index.html` bằng trình duyệt Chrome. Không cần cài đặt, chạy được ngoại tuyến.

## Đăng lên GitHub Pages

1. Tạo repository mới trên GitHub rồi tải toàn bộ file trong thư mục này lên.
2. Vào **Settings → Pages**.
3. Ở mục **Branch**, chọn `main` và thư mục `/ (root)`, sau đó bấm **Save**.
4. Sau ít phút, trò chơi chạy tại `https://<tên-tài-khoản>.github.io/<tên-repo>/`.

## Giáo viên

Nút ⚙️ ở màn hình đầu cho phép chọn lại đáp án đúng và sửa lời giải thích. Nội dung câu hỏi và các phương án được cố định. Thay đổi được lưu trên trình duyệt đang dùng.
